# Technology Decision Record

## Express

Chosen because it provides a lightweight and widely adopted framework for REST APIs.

Alternative considered:
Fastify

Reason not selected:
Express has a simpler ecosystem for this assignment.

---

## NodeCache

Chosen for lightweight in-memory caching.

Alternative considered:
Redis

Reason not selected:
Persistent distributed caching was unnecessary for the expected assignment scope.

---

## Jest

Chosen for automated testing.

Alternative considered:
Mocha

Reason not selected:
Jest provides assertions, mocking, and test execution in one framework.

---

## Render

Chosen for deployment.

Alternative considered:
Railway

Reason not selected:
Render offers straightforward deployment with GitHub integration.
